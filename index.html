Hands-On with Dynamics 365, Power Automate & Power BI

Analyst / D365 Consultant

Reporting from Dynamics 365 relied on a manual process — extract data, upload to SharePoint, refresh Power BI. I built a Power Platform proof-of-concept that automates the whole chain:

  • Extracts data from Dynamics 365 Business Central (same pattern applies to D365 CE via Dataverse)
  • Transforms it into a structured CSV
  • Uploads it to OneDrive/SharePoint
  • Refreshes the Power BI dataset on a schedule

Power Automate couldn't consume the existing D365 personal view directly, so I rebuilt the logic as a FetchXML query joining Accounts and System Users, selecting only the required fields.

Order Reconciliation Agent

Independent project

An automation agent combining a JotForm webhook, the Twilio API, and Claude to reconcile customer orders end-to-end. Orders submitted via WhatsApp/Facebook trigger the webhook, the agent checks PayPal's API for a matching payment, updates status in a tracking sheet, and sends the customer an SMS confirmation via Twilio — unmatched orders are automatically rechecked hourly rather than needing manual follow-up.
